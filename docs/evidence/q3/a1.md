# Q3 — Cost model + unit economics

## Assumptions

| Parameter | Value | Rationale |
|---|---|---|
| Messages per user per day | 15 | Legal associates do 3–5 research sessions/day; each session ~3 messages |
| Avg tokens in per message | 2,500 | System prompt (~800) + RAG chunks (~1,200) + user query (~300) + conversation history (~200) |
| Avg tokens out per message | 600 | Structured markdown output (clause tables, draft redline language) |
| RAG queries per message | 1.5 | ~50% of messages trigger Qdrant; complex tasks trigger 2 queries |
| File uploads | 5 MB/user/month | ~1 large PDF (new SPA) + smaller attachments |
| Qdrant corpus size | 3M vectors, 1536-dim | Full legal corpus for 120-lawyer firm, 15 years of executed agreements |
| S3 egress | 0.5 GB/user/month | Downloads of generated redline docs and exported reports |
| Working days/month | 22 | Business-hours usage pattern; near-zero weekend traffic |
| LLM pricing (primary) | OpenRouter — `anthropic/claude-sonnet-4-5`: $3/M input, $15/M output | Representative model for structured legal reasoning |
| LLM pricing (fallback) | AWS Bedrock Claude Sonnet: $3/M input, $15/M output (eu-west-1) | Compliance fallback; same pricing tier |

> **Note on LLM cost dominance:** At 10 MAU, LLM is 33% of the bill; at 1,000 MAU it is 79%. The stack's cost curve is driven by token volume, not infrastructure. The fixed-cost floor (RDS Multi-AZ + Qdrant EC2) is ~$450/month regardless of user count.

## Top 3 cost drivers at 1,000 MAU

1. **LLM tokens — $4,929/month (79% of total).** At 330,000 messages/month × 3,100 tokens avg, the inference spend dominates all other line items combined. The split between input and output matters: input is cheap ($3/M), output is expensive ($15/M). Minimising output verbosity — e.g. instructing the model to return JSON instead of prose for structured tasks — cuts output tokens by 30–40% with no user-visible quality loss for machine-readable outputs.

2. **RDS Postgres 16 Multi-AZ — $381/month (flat cost, scale-independent above 10 MAU).** The Multi-AZ standby runs 730 hours/month whether there are 10 or 10,000 users. At 10 MAU it is 30% of the non-LLM bill; at 1,000 MAU it is 6%. The decision to run Multi-AZ is correct for prod (message history and agent configs are irreplaceable), but the cost is front-loaded.

3. **ALB — $120/month at 1,000 MAU.** LobeChat uses Server-Sent Events for streaming responses. Each active chat session holds an open HTTP/2 connection for the duration of the LLM response (20–60 seconds). At 1,000 MAU with a peak concurrency of ~100 simultaneous sessions, the ALB accumulates LCU charges for active connections, not just requests. Connection-oriented pricing penalises streaming architectures at scale.

## Cost-cutting levers

### Lever 1 — Switch to a fine-tuned open-weight model on EC2 GPU (for high-volume background tasks)

**Estimated saving at 1,000 MAU: ~$3,200/month (51% reduction in LLM spend).**

Running `meta-llama/Llama-3.3-70B-Instruct` via vLLM on 1× `g6.12xlarge` (4× A10G GPU, $3.99/hr on-demand, $2.48/hr spot) handles background workloads: bulk clause extraction, nightly re-indexing, batch analysis. Interactive sessions continue to use OpenRouter for latency.

At spot pricing: $2.48 × 730 hr = **$1,810/month** for the GPU instance. If 65% of message volume is non-interactive (background pipelines, batch jobs), routing that 65% to self-hosted inference eliminates 65% × $4,929 = $3,204 in OpenRouter spend. Net: save $3,200, spend $1,810 → **net saving ~$1,390/month**. At 1,000 MAU this is a ~22% total bill reduction. At higher scale the saving grows linearly with volume while the GPU cost is fixed.

**SLO trade-off:** Self-hosted 70B on A10G delivers ~1.5–2s TTFT vs <500ms via OpenRouter API. Acceptable for background batch tasks; noticeable regression for interactive drafting. Mitigation: route based on session type (batch vs. interactive), not user.

### Lever 2 — Aggressive RAG context truncation via metadata pre-filtering

**Estimated saving at 1,000 MAU: ~$740/month (12% reduction in LLM spend).**

Current: each RAG message injects 8 chunks × ~180 tokens = 1,440 tokens into the input context. If 40% of queries specify a clause type (e.g. "limitation of liability, governing law"), pre-filtering by `clause_type` metadata before vector search reduces the result set to 3–4 chunks — saving ~720 input tokens per RAG message.

At 1,000 MAU: 330,000 msg/mo × 40% RAG-filtered × 720 tokens saved × $3/M = **$285/month** input saving. Combined with tighter system prompts (trimming boilerplate from 800 to 400 tokens where possible): additional **$456/month**. Total: ~$740/month at current model pricing.

**SLO trade-off:** Fewer chunks increases the risk of missing a relevant precedent. Mitigation: two-stage retrieval via a Hayhooks pipeline (broad vector search → metadata filter → re-rank top-4 by BM25 hybrid score). Quarterly evaluation on a held-out test set of known clause-type pairs; recall@4 must be ≥ 0.88 before enabling in prod.

## Unit economics

| Scale | Total monthly cost | Active users | Cost / user / month |
|---|---|---|---|
| 10 MAU | $833 | 10 | **$83.30** |
| 100 MAU | $1,125 | 100 | **$11.25** |
| 1,000 MAU | $6,247 | 1,000 | **$6.25** |

**Where does the curve break?**

The unit cost drops 7× between 10 and 100 MAU. This is the fixed-cost absorption effect: the RDS Multi-AZ instance ($254/mo), Qdrant EC2 ($147/mo), and base Fargate allocation (~$60/mo) are shared infrastructure that does not scale with users. At 10 MAU these fixed costs are $461/$833 = **55% of the bill**; at 1,000 MAU they are $792/$6,247 = **13%**.

The curve flattens near-linearly above ~50 MAU, where LLM token cost becomes the dominant driver and marginal cost per new user converges to ~$5–6/month (pure token fees). The meaningful "break" is between 10 and 50 MAU — getting past that range cuts per-user cost from ~$80 to ~$15.

## Pricing recommendation

At 100 MAU, cost is **$11.25/user/month**. To cover cost + 50% gross margin:

**Price = $11.25 ÷ (1 − 0.50) = $22.50/user/month**

**Recommended price: $25/user/month** (rounding up for support overhead and monitoring tools not captured in AWS line items).

For context: ChatGPT Enterprise is ~$60/user/month; Microsoft Copilot M365 is ~$30/user/month. At $25/user/month, the self-hosted stack is 2× cheaper than the cheapest mainstream SaaS alternative while delivering a proprietary RAG knowledge base over the firm's own corpus, full data sovereignty, and model flexibility — none of which SaaS provides at any price.

At 1,000 MAU the margin improves further: $6.25 cost → $12.50/user/month at 50% margin, giving meaningful room to invest in model quality improvements or reduce price to win enterprise deals.
