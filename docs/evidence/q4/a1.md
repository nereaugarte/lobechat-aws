## TL;DR

- **Self-host wins on 3-year TCO** at ≥ 100 users: $432k vs $1.44M (ChatGPT Enterprise) or $720k (Copilot M365) for 200 users — a saving of $1M–$1.5M over 3 years when headcount grows linearly.
- **Self-host is the only option that satisfies our GDPR obligations** for client-confidential deal documents without individual DPA amendments per client — a legal constraint, not a preference.
- **Self-host provides capabilities SaaS cannot replicate**: semantic search over our proprietary corpus of 3,200 executed SPAs, MCP tool integration with our internal document systems, and model freedom (swap models without vendor contract changes).

## Lock-in Analysis

| Dimension | Self-hosted (LobeChat) | ChatGPT Enterprise | Copilot M365 |
|---|---|---|---|
| **Data** | All data in our AWS account (Postgres, S3, Qdrant). Export: `pg_dump` + `aws s3 sync`. Exit cost: ~1 day of engineering. | Data in OpenAI US infra. Export: API or manual download. Portability: good in principle, limited in practice for conversation history. | Data in Microsoft 365 tenant. Deeply integrated with OneDrive/SharePoint. Exit cost: significant if also on M365. |
| **Identity** | Casdoor OIDC, swappable to any IdP. | Tied to Azure AD (Entra ID). | Tied to Azure AD. Exit = re-provision IdP. |
| **Model** | Change `OPENROUTER_DEFAULT_MODEL` env var. No contract change. Zero switching cost. | OpenAI decides model; enterprise gets GPT-4o today, may get future model without opt-in. | Microsoft decides; currently GPT-4o + M365-tuned. |
| **Tooling / integrations** | MCP protocol (open standard). Any MCP server plugs in. | Custom GPTs via API. Plugins via OpenAI platform. Proprietary extension model. | Copilot extensibility via Graph connectors. Proprietary. |
| **Exit cost** | Low. Data is ours. Stack is open-source. Migrate to any compatible stack in days. | Medium. Conversation history portable; custom GPT configurations not. Re-training prompt templates: 1–2 weeks. | High if M365-embedded. Conversation history, SharePoint integrations, Teams bots — all Microsoft-specific. |

**Critical observation on model lock-in:** ChatGPT Enterprise does not let you specify which GPT-4 variant you run. When OpenAI deprecated GPT-4-turbo in favour of GPT-4o, Enterprise customers were migrated automatically. For a legal firm where "the AI changed its reasoning style" is a professional liability event, model stability matters. With self-hosted OpenRouter, we pin the model version (`anthropic/claude-sonnet-4-5:2025-01-01`) and migrate on our own schedule.

## Data Sovereignty and Compliance

**The hard constraint:** The firm's GDPR Data Processing Agreements with M&A clients contain explicit data residency clauses: *"Personal data and client-confidential commercial information shall not be transferred to or processed by sub-processors outside the EU/EEA without prior written consent and an updated DPA."*

ChatGPT Enterprise processes data in OpenAI's US data centres (with EU commercial agreements available via Azure OpenAI — but that requires a separate enterprise contract, negotiated separately from the standard ChatGPT Enterprise offering, at higher cost). Microsoft Copilot for M365 can be configured to stay in EU (Microsoft EU Data Boundary), but audit of sub-processors is constrained by Microsoft's standard DPA.

Self-hosted on EC2 `eu-west-1`: data never leaves our AWS account. There are zero sub-processors. The only third-party data processor is OpenRouter for LLM inference — and OpenRouter is used only for the prompt/response, never for storing documents. If GDPR exposure on the inference layer is also a concern, AWS Bedrock in `eu-west-1` provides inference with no data storage and full EU jurisdiction, at equivalent pricing.

**Sector-specific (legal):** Bar association professional conduct rules in multiple EU jurisdictions (Spain, UK, Germany) require solicitors to maintain client confidentiality even from cloud providers. The Law Society of England and Wales guidance (October 2023) explicitly warns against uploading client documents to "AI services operated by third parties without adequate DPA coverage." Self-hosting eliminates this compliance exposure entirely. Using ChatGPT Enterprise requires per-client DPA amendments — a 6–8 week legal process per client that creates a material bottleneck for new matter onboarding.

## Capability Gap

**What self-hosted does that SaaS cannot:**

1. **Semantic search over our proprietary corpus.** 3,200 executed SPAs, indexed in Qdrant with metadata filtering. ChatGPT cannot see this data. Copilot can search SharePoint, but SharePoint full-text search is not vector semantic search — it does not retrieve by meaning, only by keyword. The proprietary knowledge base is a compounding competitive advantage: every new matter indexed makes the system more accurate, and no competitor using ChatGPT can replicate it.

2. **MCP tool integration.** `filesystem-write_file` writes redlines directly to `/data/matters/`. `qdrant-mcp` runs filtered vector queries. `hayhooks-mcp` runs Haystack pipelines for structured clause extraction. SaaS AI tools do not integrate with on-premise document systems without a dedicated connector build — which itself costs 3–6 months of engineering, at which point the TCO advantage of SaaS disappears.

3. **Model choice and version pinning.** When a legal-domain fine-tuned model ships (e.g. Harvey AI's base model, or an open-weight model fine-tuned on EU contract law), we can deploy it within hours. SaaS users wait for vendor roadmaps.

**What SaaS does that self-hosted does not (honestly):**

- **Uptime SLA.** OpenAI and Microsoft guarantee 99.9% uptime. Our ECS stack with RDS Multi-AZ and ALB health checks targets 99.5% — not contractually guaranteed. For a firm where downtime during a deal close is a crisis, this gap is real.
- **Mobile apps.** ChatGPT and Copilot have polished iOS/Android clients. LobeChat's mobile experience is a responsive web UI — functional but not native.
- **Automatic model refresh.** SaaS customers get newer models without any action. Self-hosted requires deliberate upgrade cycles.
- **Enterprise support.** 24/7 vendor support with SLAs. Self-hosted = internal DevOps response.

## Recommendation

**Self-host LobeChat if:** (a) you have ≥ 50 active users (economics turn positive), (b) client-confidential documents are the primary corpus, (c) you have or will hire 0.5 FTE of DevOps capacity, and (d) proprietary RAG over internal knowledge is the core value proposition.

**Buy SaaS (ChatGPT Enterprise or Copilot) if:** (a) the primary use case is productivity on public knowledge (drafting emails, summarising news, code assistance), (b) you have no engineering capacity to operate infrastructure, or (c) your clients explicitly require vendor SLAs in the contract.

For a 200-lawyer M&A firm where the corpus is proprietary deal documents and GDPR compliance is non-negotiable: **self-host. The decision is not close.**

---

## Reversal Trigger

This recommendation flips if **any two** of the following occur simultaneously:

1. **OpenAI or Microsoft launch an EU-sovereign, on-premise deployment option at ≤ $30/user/month.** (Azure OpenAI Provisioned Throughput in EU exists but is currently $90k+/year minimum commitment — not competitive at our scale.)
2. **The cost of running 0.5 DevOps FTE rises above $100k/year** (senior hire in a high-cost city) and the team has no existing cloud operations capability to absorb it.
3. **A data breach or high-profile failure in a self-hosted legal AI stack** triggers regulatory guidance that mandates certified cloud AI providers — similar to how EU banking regulators have moved on cloud outsourcing.

If any single one of these occurs, re-evaluate in 90 days. If two occur concurrently, initiate an RFP for Azure OpenAI Service (not standard ChatGPT Enterprise — Azure gives data residency guarantees that standard ChatGPT does not).
